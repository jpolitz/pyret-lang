Pyret — CodeMirror 6 + Lezer (syntax highlighting, indentation, folding)

Plain editor only — nothing is compiled or run. Try editing, folding (gutter), and pressing Enter inside a block.

— Tab reindents the current line, Shift+Tab dedents, Ctrl/Cmd+Alt+L reindents everything; typing end/else/| auto-fixes the line.

Note: comments (#… and #| … |#) are highlighted by a regex overlay, because Pyret's tokenizer skips comments so they never reach the Lezer tree.
